# Casa dos Pensamentos

Museu virtual 3D público para pensamentos, sentimentos, arte e ideias.

> Um museu de tudo aquilo que vive dentro de mim.

## Desenvolvimento

Site estático inicial com Three.js, sem contas, segredos ou dados pessoais. Conteúdos de demonstração são fictícios. A publicação persistente e o painel administrativo serão adicionados numa etapa futura com autenticação e base de dados.

## Executar

Abra `index.html` num servidor local (por exemplo `python3 -m http.server 8000`) ou publique como site estático no Render com diretório `.`. Não há comando de build.
